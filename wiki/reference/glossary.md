# Glossar

| Begriff | Bedeutung |
| --- | --- |
| **Azimut** | Flugrichtung beim Start, im Uhrzeigersinn ab Norden (90° = Osten). Bestimmt zusammen mit der Breite die Inklination. |
| **Bandwagon** | SpaceX-Rideshare-Programm für mittlere Inklinationen (ca. 45°). |
| **Captive** | Nachfrage, die für Isar nicht offen ist, weil sie auf eigenen oder vorab vergebenen Raketen fliegt (Starlink, China, Russland, Kuiper/OneWeb). |
| **CubeSat** | Standardisierter Kleinstsatellit aus 10-cm-Einheiten, meist unter 50 kg. |
| **Dedizierter Start** | Ein Start, bei dem ein Kunde Orbit und Termin bestimmt, statt als Mitfahrer zu fliegen. |
| **Dogleg** | Kurswechsel während des Aufstiegs, um eine andere Inklination zu erreichen; kostet Nutzlast. |
| **ELC** | ESA European Launcher Challenge, Förderprogramm für europäische Startanbieter (Isar: 197,8 Mio. €). |
| **FTI** | ESA/EU Flight Ticket Initiative, Rahmenverträge für Startplätze institutioneller Missionen. |
| **GCAT** | General Catalog of Artificial Space Objects von Jonathan McDowell, öffentlicher Katalog aller Objekte im All. |
| **GEO / GTO** | Geostationärer Orbit (ca. 36.000 km, 0°) bzw. die Transferbahn dorthin. |
| **HASTE** | Suborbitale Variante von Rocket Labs Electron für Hyperschall-Tests der US-Verteidigung. |
| **Inklination** | Neigung der Bahnebene gegen den Äquator: 0° äquatorial, 90° polar, über 90° retrograd. |
| **IRIS²** | Geplante EU-Konstellation für sichere Kommunikation (348 Satelliten, erste Starts 2029). |
| **ITAR** | US-Exportkontrollregeln für Rüstungs- und Raumfahrttechnik. |
| **Kadenz** | Anzahl der Starts pro Zeitraum. |
| **Kick-Stage** | Zusätzliche kleine Oberstufe, die Satelliten nach dem Start in ihre Zielbahnen bringt. |
| **LEO** | Niedriger Erdorbit, bis ca. 2.000 km Höhe. |
| **LOX** | Flüssigsauerstoff, Oxidator von Spectrum (zusammen mit Propan). |
| **MEO** | Mittlerer Erdorbit (2.000 km bis GEO), z. B. Navigationssatelliten. |
| **NSPM-17** | US-Richtlinie (2026): US-Regierungsnutzlasten fliegen grundsätzlich mit US-Raketen. |
| **Rideshare** | Mitflug vieler Satelliten auf einer großen Rakete (z. B. SpaceX Transporter), billig pro kg, aber ohne Wahl von Orbit und Termin. |
| **SAR** | Synthetic Aperture Radar, Radar-Erdbeobachtung; asiatische Betreiber oft auf 37–45°, europäische Verteidigungs-SAR meist sonnensynchron. |
| **Smallsat** | Kleinsatellit; BryceTech zählt bis 1.200 kg, Novaspace bis 500 kg. |
| **SSO** | Sonnensynchroner Orbit, ca. 97–99° Inklination; der Satellit überfliegt jeden Ort zur gleichen Ortszeit. Standard für Erdbeobachtung. |
| **TAM / SAM / SOM** | Total / Serviceable / Obtainable Market: Gesamtmarkt, für uns bedienbarer Markt, realistisch gewinnbarer Anteil. |
| **Transporter** | SpaceX-Rideshare-Programm in den SSO. |
| **TSA** | Technology Safeguards Agreement: Abkommen mit den USA, ohne das US-gebaute Satelliten nicht aus einem Land starten dürfen. |
| **Upmass** | Gesamte in den Orbit gebrachte Masse pro Zeitraum. |
